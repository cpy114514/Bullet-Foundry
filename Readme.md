# Bullet Foundry

> Build towers. Shape bullets. Fight against enemies. Create levels. Share them with the community.

Bullet Foundry is black and white hand drawing(Trust my drawing skill☜(ﾟヮﾟ☜)) towerdefense game. Unlike other towerdefense, it only have one shooter that can attack. The towers will only have reaction when bullets hits them. Build defense by the different combination of the towers. ᐠ( ᐛ )ᐟ You can also create your own levels and share it in the community or try others levels(or you can just post some random things...).

## Game modes
### Normal levels

There are 12 normal levels and a boss level(my little brother made them Σ(°Д°))
### Infinity mode

You can kept fighting untill last tower stands.
### Sandbox mode

Sandbox mode allows you to place any tower or enemy you want and watch them fight(make sure your PC won't crush...)

## Level Editor

There is a level Editor that allows player to make their own levels by draging enemies to the timeline. You can publish it in the community or export it as json to share with others.
## Community

This is a place that allows people to socialize, chating with each other. You can post anything you want(Image, Text, Levels). You can also comment on others post or have some fun with playing levels others made.

## How to play

### Normal games

Drag the towers to place them, towers that is already being placed can still move.
w/s, up/down or drag to move the shooter.

### Level editor

Drag enemy cards to the timeline to place enemies.
Scroll or use press mouse wheel to move the timeline.
Use ctrl + scroll to zoom the timeline
Undo| ctrl + z
Redo| ctrl + y
Right click on the card to delete or change the number of enemy
